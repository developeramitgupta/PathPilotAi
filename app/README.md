# App

The deployable PathPilot web application.

- `src/app` — Next.js pages, layouts, and API routes
- `src/components` — reusable screens and UI primitives
- `src/features` — product logic and server-side feature services
- `src/lib` — shared clients, schemas, datasets, and utilities
- `src/stores` — browser state
- `public` — public images and app assets

Run it from the workspace root with `npm run dev`, or from this directory with `npm run dev`.

For Vercel, configure `app` as the project Root Directory.
